💡
¿Qué es un Microfrontend y por qué usarlo?
Entiende el concepto antes de escribir código
Un microfrontend (MFE) es una aplicación web pequeña e independiente que hace una sola cosa: por ejemplo, mostrar usuarios, gestionar transacciones o mostrar reportes. Varias de estas apps pequeñas se combinan para formar una app grande que el usuario ve como una sola.

Piénsalo así: en lugar de tener un restaurante donde un solo cocinero hace todo, tienes estaciones separadas — una para entradas, otra para platos fuertes, otra para postres. Cada una trabaja de forma independiente pero el comensal recibe una experiencia unificada.

✅ Ventajas
Cada módulo se puede desarrollar, probar y desplegar de forma independiente. Equipos diferentes pueden trabajar sin bloquearse entre sí. Un bug en un módulo no rompe los otros.
🏗 Cómo funciona en este proyecto
El host (puerto 3000) tiene el sidebar y la navegación principal. Cada MFE (puerto 3001, 3002…) es una app Next.js separada que se muestra dentro del host usando un iframe.
localhost:3000 → Host (dashboard-nextjs) — sidebar + topbar
└── /dashboard/users → <iframe> apuntando a → localhost:3002
└── /dashboard/transactions → <iframe> apuntando a → localhost:3001
Cada MFE llama a la API del host → localhost:3000/api/users
ℹ️ En este proyecto el MFE de Transacciones ya existe en transactions-mfe/. Vamos a crear uno nuevo para Usuarios siguiendo exactamente el mismo patrón.

Crear next.config.ts — el archivo más importante del MFE
El basePath es la ruta bajo la cual correrá este MFE. Debe coincidir con la ruta que le asignarás en el host (por ejemplo /dashboard/users). 
users-mfe/next.config.tsimport type { NextConfig } from "next";

const nextConfig: NextConfig = {
  // basePath: todas las rutas del MFE quedan bajo /dashboard/users
  // Ejemplo: app/page.tsx → http://localhost:3002/dashboard/users
  // Ejemplo: app/new/page.tsx → http://localhost:3002/dashboard/users/new
  basePath: "/dashboard/users",
};

export default nextConfig;
⚠️ Regla clave: el basePath del MFE debe ser idéntico a la ruta donde lo vas a incrustar en el host. Si el módulo va en /dashboard/users, el basePath es "/dashboard/users".

2
Crear app/components/EmbeddedShell.tsx — detecta si está en iframe
Este componente es el cerebro del MFE. Detecta automáticamente si el MFE está siendo mostrado dentro del host (iframe) o abierto directamente en el navegador.

• Dentro del host → muestra solo el contenido (sin sidebar propio)
• Directo en :3002 → muestra el layout completo con sidebar 
users-mfe/app/components/EmbeddedShell.tsx"use client";

import { useState, useEffect } from "react";

export default function EmbeddedShell({
  children
}: { children: React.ReactNode }) {
  const [isEmbedded, setIsEmbedded] = useState(false);

  useEffect(() => {
    try {
      // Si window.self !== window.top, estamos dentro de un iframe
      setIsEmbedded(window.self !== window.top);
    } catch {
      // Error cross-origin = definitivamente en iframe
      setIsEmbedded(true);
    }
  }, []);

  // Modo embebido: solo el contenido, el host pone el sidebar
  if (isEmbedded) {
    return (
      <div style={{ backgroundColor: "var(--background)", minHeight: "100vh" }}>
        {children}
      </div>
    );
  }

  // Modo standalone: muestra el layout completo
  return (
    <div style={{ display: "flex", minHeight: "100vh", backgroundColor: "var(--background)" }}>
      <main style={{ flex: 1, padding: "24px" }}>
        <h1 style={{ fontSize: "1.5rem", fontWeight: 800, marginBottom: "20px",
          color: "var(--text-primary)" }}>
          Módulo de Usuarios
        </h1>
        {children}
      </main>
    </div>
  );
}

users-mfe/app/page.tsx"use client";

import { useEffect, useState } from "react";

// Tipo de datos de un usuario (debe coincidir con tu modelo en MongoDB)
type User = {
  _id: string;
  name: string;
  email: string;
  role: string;
  createdAt: string;
};

// Gradientes para los avatares de usuarios
const GRADIENTS = [
  "linear-gradient(135deg,#6366f1,#4f46e5)",
  "linear-gradient(135deg,#a78bfa,#7c3aed)",
  "linear-gradient(135deg,#38bdf8,#0284c7)",
  "linear-gradient(135deg,#34d399,#059669)",
  "linear-gradient(135deg,#fb7185,#e11d48)",
];

const Avatar = ({ name }: { name: string }) => {
  const ch = name?.charAt(0)?.toUpperCase() ?? "?";
  const g  = GRADIENTS[(ch.charCodeAt(0) - 65) % GRADIENTS.length];
  return (
    <div style={{ width: "36px", height: "36px", borderRadius: "50%", background: g,
      display: "flex", alignItems: "center", justifyContent: "center",
      color: "white", fontWeight: 700, fontSize: "14px", flexShrink: 0 }}>
      {ch}
    </div>
  );
};

export default function UsersPage() {
  const [users, setUsers]     = useState<User[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError]     = useState<string | null>(null);

  // URL del host — definida en .env.local
  const API = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:3000";

  useEffect(() => {
    const load = async () => {
      try {
        const res = await fetch(`${API}/api/users`);
        if (!res.ok) throw new Error(`Error ${res.status}`);
        const data = await res.json();
        setUsers(data);
      } catch (e) {
        setError(e instanceof Error ? e.message : "Error desconocido");
      } finally {
        setLoading(false);
      }
    };
    load();
  }, [API]);

  const formatDate = (iso: string) =>
    new Date(iso).toLocaleDateString("es-MX", { year: "numeric", month: "short", day: "numeric" });

  return (
    <div style={{ padding: "24px" }}>

      {/* Encabezado */}
      <div style={{ marginBottom: "20px" }}>
        <h2 style={{ fontSize: "1.25rem", fontWeight: 800, color: "var(--text-primary)" }}>
          Lista de Usuarios
        </h2>
        <p style={{ fontSize: "0.8rem", color: "var(--text-secondary)", marginTop: "4px" }}>
          Datos desde {API}/api/users
        </p>
      </div>

      {/* Card contenedora */}
      <div style={{ background: "white", borderRadius: "12px",
        boxShadow: "var(--shadow-card)", overflow: "hidden" }}>

        {/* Cargando */}
        {loading && (
          <div style={{ padding: "48px", textAlign: "center", color: "var(--text-disabled)" }}>
            Cargando usuarios...
          </div>
        )}

        {/* Error */}
        {error && (
          <div style={{ padding: "48px", textAlign: "center", color: "#dc2626" }}>
            {error} — ¿El host está corriendo en {API}?
          </div>
        )}

        {/* Tabla de usuarios */}
        {!loading && !error && (
          <table style={{ width: "100%", borderCollapse: "collapse", fontSize: "14px" }}>
            <thead>
              <tr style={{ backgroundColor: "#F4F6F8",
                borderBottom: "1px solid rgba(145,158,171,0.24)" }}>
                {["Usuario", "Email", "Rol", "Registrado"].map(h => (
                  <th key={h} style={{ padding: "12px 20px", textAlign: "left",
                    fontSize: "11px", fontWeight: 700, textTransform: "uppercase",
                    color: "var(--text-secondary)", letterSpacing: "0.07em" }}>
                    {h}
                  </th>
                ))}
              </tr>
            </thead>
            <tbody>
              {users.map((user, idx) => (
                <tr key={user._id}
                  style={{ borderBottom: idx === users.length - 1 ? "none"
                    : "1px solid rgba(145,158,171,0.10)" }}>
                  <td style={{ padding: "14px 20px" }}>
                    <div style={{ display: "flex", alignItems: "center", gap: "12px" }}>
                      <Avatar name={user.name} />
                      <span style={{ fontWeight: 600, color: "var(--text-primary)" }}>
                        {user.name}
                      </span>
                    </div>
                  </td>
                  <td style={{ padding: "14px 20px", color: "var(--text-secondary)" }}>
                    {user.email}
                  </td>
                  <td style={{ padding: "14px 20px" }}>
                    <span style={{
                      background: user.role === "admin"
                        ? "rgba(124,58,237,0.12)" : "rgba(79,70,229,0.10)",
                      color: user.role === "admin" ? "#7c3aed" : "#4f46e5",
                      border: user.role === "admin"
                        ? "1px solid rgba(124,58,237,0.24)"
                        : "1px solid rgba(79,70,229,0.20)",
                      padding: "3px 10px", borderRadius: "20px",
                      fontSize: "11px", fontWeight: 700
                    }}>
                      {user.role}
                    </span>
                  </td>
                  <td style={{ padding: "14px 20px", color: "var(--text-secondary)",
                    fontSize: "13px" }}>
                    {formatDate(user.createdAt)}
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        )}
      </div>
    </div>
  );
}

Habilitar CORS en la API del host
Permite que el MFE (puerto 3002) acceda a los datos del host (puerto 3000)
CORS (Cross-Origin Resource Sharing) es una protección del navegador que impide que una página web pida datos de un servidor diferente. Como el MFE corre en el puerto 3002 y la API está en el puerto 3000, son orígenes distintos y el navegador bloquearía las peticiones.

La solución: decirle al servidor del host "acepta peticiones del puerto 3002".
1
Editar app/api/users/route.ts en el host
Si no existe este archivo, créalo. Agrega los headers CORS y el handler OPTIONS. 
dashboard-nextjs/app/api/users/route.tsimport { NextResponse } from "next/server";
import { connectDB } from "@/app/src/lib/mongodb";
import { User } from "@/app/src/models/User";

// ↓ Esto permite que el MFE en :3002 pueda hacer fetch a esta API
const CORS_HEADERS = {
  "Access-Control-Allow-Origin":  "http://localhost:3002",
  "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type, Authorization",
};

// Este handler responde al "preflight" que envía el navegador antes del fetch
export async function OPTIONS() {
  return new NextResponse(null, { status: 204, headers: CORS_HEADERS });
}

export async function GET() {
  await connectDB();
  const data = await User.find().sort({ createdAt: -1 });
  return NextResponse.json(data, { headers: CORS_HEADERS });
}
⚠️ Reinicia el host después de editar cualquier route.ts: rm -rf .next && npm run dev

1
Crear (o reemplazar) app/dashboard/users/page.tsx en el host

dashboard-nextjs/app/dashboard/users/page.tsx/**
 * Página /dashboard/users del host
 *
 * Renderiza el MFE de Usuarios dentro del layout del host
 * usando un iframe. El MFE detecta que está embebido y
 * muestra solo el contenido (sin su propio sidebar/topbar).
 */
export default function UsersPage() {
  return (
    <iframe
      src="http://localhost:3002/dashboard/users"
      title="Módulo de Usuarios"
      style={{
        width:   "100%",
        // 100vh menos la altura del TopBar del host (64px)
        height:  "calc(100vh - 64px)",
        border:  "none",
        display: "block",
        backgroundColor: "var(--background)",
      }}
    />
  );
}
2
Actualizar el link "Usuarios" en el Sidebar del host
El link de Usuarios en el Sidebar usa <Link> de Next.js. Como ahora la página del host carga un iframe (no navega a otro servidor), el <Link> funciona correctamente y no necesita cambio.

Solo verifica que en app/src/components/organisms/Sidebar/index.tsx el item de Usuarios no tenga mfe: true: 
dashboard-nextjs/app/src/components/organisms/Sidebar/index.tsxconst NAV_MANAGEMENT: NavItem[] = [
  { href: "/dashboard/users",        label: "Usuarios",      icon: <IconUsers /> },
  // Sin mfe:true → usa <Link> normal, el host carga su propia página con el iframe

  { href: "/dashboard/transactions", label: "Transacciones", icon: <IconTransactions />,
    mfe: true },
  // Con mfe:true → usa <a> nativo, necesario solo si el rewrite apunta a otro servidor

✅ ¿Por qué Usuarios no necesita mfe:true? Porque la página /dashboard/users del host existe y solo contiene un iframe. Next.js la sirve normalmente con el Link. El MFE se carga dentro de esa página, no como una app separada que reemplaza el host.

El iframe muestra error de conexión:

El CORS no está configurado o la API no existe. Verifica que app/api/users/route.ts en el host tenga los headers CORS con el puerto 3002.

Los estilos se ven diferentes al host:
